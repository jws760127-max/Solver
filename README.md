# 찍으면 풀이 (안드로이드)

휴대폰 기본 카메라로 문제를 찍기만 하면, 몇 초 안에 알림으로 답이 오고 소리로 읽어 주는 앱이에요.
무료 Gemini API로 동작해요.

## 받기
이 저장소의 **Releases → 찍으면 풀이 (최신) → SnapSolver.apk** 를 휴대폰에서 눌러 받아 설치하세요.
처음 설치할 때 "출처를 알 수 없는 앱 설치 허용"을 한 번 켜야 해요.

## 처음 설정 (앱 안에 안내가 있어요)
1. 무료 Gemini 키 넣기 (aistudio.google.com/apikey)
2. 사진·알림 권한 허용 (사진은 **모두 허용**)
3. 배터리 제한 풀기 (꺼지지 않게)
4. **자동 풀이 켜기**

## 쓰는 법
- 자동 풀이를 켜 두고, 평소처럼 카메라로 문제를 찍으면 끝이에요.
- 갤러리 사진은 **공유 → 찍으면 풀이로 풀기**로 보내도 돼요.
- 필요 없을 때는 알림의 **끄기**를 누르세요.

> 자동 풀이가 켜져 있는 동안 찍는 사진은 Gemini로 보내져요. 문제가 아닌 사진은 조용히 넘어가요.
> Gemini 무료 등급은 보낸 내용이 Google 서비스 개선에 쓰일 수 있어요.

코드를 고치면 GitHub Actions가 자동으로 새 APK를 만들어 Releases에 올려요.
