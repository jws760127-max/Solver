SolveCam! 설치

책상 위 와이파이 카메라가 문제를 보고, 휴대폰·PC에서 답을 보여 주고 읽어 줘요.

1. 카메라에 프로그램 넣기 (PC 크롬·엣지)

  1. 카메라를 USB로 PC에 연결해요. ESP32-CAM은 ESP32-CAM-MB 받침 보드에 끼워서 연결해요.
  2. 아래에서 내 보드의 설치하기를 누르고, 뜨는 목록에서 포트(USB, CH340 등)를 골라 연결해요.
  3. "설치"를 누르면 1~2분 뒤 끝나요.
AI-Thinker ESP32-CAM가장 흔한 1만 원대 카메라 보드 PC의 크롬이나 엣지 브라우저에서 열어 주세요.https 주소에서만 설치할 수 있어요.
XIAO ESP32S3 Sense카메라가 달린 작은 보드 PC의 크롬이나 엣지 브라우저에서 열어 주세요.https 주소에서만 설치할 수 있어요.

포트가 안 보이면: USB 선이 충전 전용이 아닌지 확인하고, CH340 드라이버를 설치해 주세요. 연결이 실패하면 보드의 IO0(BOOT) 버튼을 누른 채 RST를 한 번 눌렀다 떼고 다시 시도해 보세요.

2. 와이파이 연결 (휴대폰으로 1분)

  1. 휴대폰 와이파이 목록에서 SolveCam-Setup에 연결해요. 설정 화면이 자동으로 떠요. 안 뜨면 브라우저에서 192.168.4.1을 열어요.
  2. 집 와이파이를 고르고 비밀번호를 넣어요. 2.4GHz 와이파이만 연결돼요.
  3. 무료 Gemini 키도 넣어요 (aistudio.google.com/apikey → API 키 만들기 → 복사). 나중에 넣어도 돼요.
  4. "연결됐어요!" 화면에 나온 주소를 적어 두세요. 예: http://192.168.0.23

3. 쓰기

  1. 휴대폰을 집 와이파이로 돌리고, 휴대폰·PC 브라우저에서 그 주소(또는 http://solvecam.local)를 열어요. 즐겨찾기나 홈 화면에 추가해 두면 편해요.
  2. 카메라를 책상 위 30~40cm 높이에 아래를 보게 달아요. 거꾸로 보이면 설정 → 화면 돌리기.
  3. 문제를 카메라 아래에 두면, 페이지가 바뀔 때마다 자동으로 풀어요. 같은 페이지는 다시 풀지 않아요.
  4. 여러 기기를 켜 두면 한 기기만 풀고, 답은 모든 기기에 같이 떠요.

소리: 각 기기에서 화면을 한 번 눌러야 답을 읽어 줄 수 있어요(브라우저 규칙). 도서관에서는 이어폰을 쓰거나 '소리 꺼짐'으로 두세요.

알아 두기

Gemini 키는 카메라에 저장되고, 같은 와이파이에 있는 기기가 쓸 수 있어요. 집이나 내 공유기에서 쓰세요. Gemini 무료 등급은 보낸 사진과 글이 Google 서비스 개선에 쓰일 수 있어요. 아두이노 IDE로 직접 올리려면 저장소의 wifi-camera/firmware/SolveCam 폴더를 여세요.
